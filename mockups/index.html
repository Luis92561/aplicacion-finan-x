Flujos que cubren los mockups

Interno: login (01) → portal de usuarios internos (14) → clientes/productos (04–05) → pedido (06) → factura (07) → pago en caja (08) → nota de crédito (09) → reportes (10).

Cliente: registro (13) o login (01) → saldo y facturas (11) → pago en línea (12): efectivo genera código Efecty; tarjeta/transferencia/cheque se registran → recuperación de contraseña con código (02).

Nota para la presentación: los textos y cifras de estas pantallas son datos ficticios para ilustrar la estructura. La aplicación final conecta estas pantallas con la base de datos real (PostgreSQL) y los cálculos se hacen siempre en el servidor.
